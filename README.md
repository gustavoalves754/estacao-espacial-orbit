# Missão Espacial: Protocolo de Homologação em Camadas

Projeto desenvolvido para a disciplina de Gestão e Qualidade de Software, com o objetivo de praticar o fluxo de desenvolvimento utilizando Git e GitHub.

## Fluxo de Ambientes

O projeto utiliza três branches que representam diferentes ambientes:

- **develop**: ambiente de desenvolvimento, onde novas funcionalidades são criadas e testadas inicialmente.
- **stage**: ambiente de homologação, utilizado para validar as alterações antes de serem enviadas para produção.
- **main**: ambiente de produção, contendo apenas funcionalidades já homologadas e aprovadas.

## Módulo de Suporte de Vida

Foi desenvolvido em Java o arquivo `SuporteVida.java`, responsável por monitorar informações básicas da estação espacial:

- Nível de oxigênio;
- Pressão do módulo;
- Sistema de reciclagem de água.
